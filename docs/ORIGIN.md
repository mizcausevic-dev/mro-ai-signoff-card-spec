# Why this draft exists

AI inspection tools can produce observations that move between vendors, MRO teams, and buyers. A finding-level record is useful only if it names the exact source artifact, model version, and human disposition together. The signature profile makes later tampering detectable when an independently trusted key is available.

This draft is intentionally narrow. It does not create staff authorization, maintenance-release authority, artifact authenticity, or regulatory compliance by itself. The signed example uses a fictional reviewer and an ephemeral test key, and its reference URLs are illustrative only.
